Roteiro de teste do widget

Página hospedeira falsa. Não há mock: o widget no canto inferior direito fala com a API real em localhost:3333.

A chave e a identidade do visitante deste <script> são gravadas por npm run seed:demo. Rode o seed antes, senão a chave pode estar revogada ou apontar para outro assistente.
  1. Abrir o chat Clique na bolha. A saudação aparece e o campo de texto fica habilitado. Se aparecer erro de chave ou domínio, o data-key está errado ou o domínio desta página não está liberado.
  2. Perguntar algo que a base não sabe Deve responder que não encontrou na base e oferecer atendimento — nunca inventar. No painel, a pergunta aparece em Lacunas e feedbacks.
  3. Cadastrar a fonte que responde, no painel Em Base de conhecimento → Adicionar fonte. Aguarde o status virar Pronta (precisa do worker rodando). Recarregue esta página e pergunte de novo: agora deve responder a partir da base.
  4. Responder a lacuna pelo painel Em Lacunas e feedbacks → Responder. A resposta vira fonte indexada e a lacuna fica Resolvida. Perguntar de novo aqui deve trazer a resposta.
  5. Dar feedback Os botões 👍/👎 abaixo de uma resposta gravam o feedback na conversa — confira em Conversas.
  6. Encaminhar para WhatsApp Com um setor configurado, abre o wa.me direto; com dois ou mais, o widget mostra os setores para escolher. Sem nenhum, responde que o encaminhamento não está configurado.
  7. Conferir no painel Em Conversas, esta conversa deve aparecer com canal widget e a transcrição completa. Se o script abaixo tiver data-external-user-id, recarregar a página abre uma conversa nova ligada ao mesmo visitante.
